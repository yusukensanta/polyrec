# PolyRec ユーザーガイド

PolyRec のインストール、検証、使い方に必要なことをまとめています。ソースからのビルドや開発への参加については、[CONTRIBUTING.ja.md](../CONTRIBUTING.ja.md) をご覧ください。

## ダウンロード / インストール

[Releases ページ](https://github.com/yusukensanta/polyrec/releases/latest) から最新版を入手してください。各バージョンで 2 種類を公開しています。

- **`polyrec-vX.Y.Z-windows-x64-setup.exe`** — 通常のインストーラーです。ダブルクリックしてウィザードを進めると、スタートメニューのショートカットと「プログラムの追加と削除」の項目が作られます。ほかのアプリと同じようにインストールしたいだけなら、こちらがおすすめです。
- **`polyrec-vX.Y.Z-windows-x64.zip`** — インストーラーなしのポータブル版です。展開して `polyrec.exe` をそのまま実行します。インストールは何も行いません。アプリは展開したフォルダーの中だけにあり、設定とログだけが `%APPDATA%\PolyRec` に保存されます。

どちらの場合も、PolyRec は起動時に新しいリリースを確認し、あればバナーを表示します。バナーをクリックすると「今すぐ更新」/「後で」の確認が開きます（更新せずにリリースノートだけを見るリンクもあります）。**今すぐ更新** を選ぶと、PolyRec はリリースをダウンロードし、公開されている `SHA256SUMS.txt` がメンテナーのリリース鍵で署名されていることを確認します。続いて、ダウンロードしたファイルの SHA256 をそれと照合し、ビルドの来歴も確認します。そのうえで、実行中の exe をその場で置き換える（ポータブル版）か、インストーラーをサイレントモードで起動し直します（インストール版。通常どおり UAC の確認が表示されます）。この確認なしに何かがダウンロードされたりインストールされたりすることはありません。

インストーラーには署名がありません（コード署名証明書なし）。そのため初回の実行時に Windows SmartScreen が「不明な発行元」の警告を表示します。**詳細情報 → 実行** をクリックしてください。その理由は [SECURITY.ja.md](../SECURITY.ja.md) をご覧ください。警告をクリックして信じるだけでなく、実行するものを自分で確かめたい場合は、下の検証手順をご覧ください。

### ダウンロードの検証（任意）

各リリースには、`SHA256SUMS.txt`、その署名 `SHA256SUMS.txt.minisig`、そしてインストーラーと zip の両方を対象とするビルドの来歴証明が含まれています。リリースページのファイルが CI で実際にビルドされたものだと、ただ信じる必要はありません。

署名（[minisign](https://jedisct1.github.io/minisign/) が必要です。例: `winget install jedisct1.minisign`）— チェックサムが、メンテナーがリリース鍵で署名したものであることを確認します。リリース鍵は GitHub には一切置いていないので、GitHub アカウントに侵入した人でもこの署名は作れません。

```powershell
minisign -Vm SHA256SUMS.txt -P RWRjDayf52/Qtwseb0oGvRR1EXVtD48nEi6j0j0Pg9POeALygRz7w8RF
# 「Signature and comment signature verified」と、trusted comment「polyrec vX.Y.Z」が表示されます
```

これはリリース鍵です。万一リリースがバックアップ鍵で署名されている場合は、`-P RWQ0RXHEI1lTp5pQZW2Ps4TceBQIxt0u2vPiXVlGWc8bf3GNXQ8o9seZ` で確認してください。どちらの鍵もリポジトリの [`keys/`](../keys) フォルダーにあります。v0.5.161 より前のリリースには署名がありません。

チェックサム（PowerShell）:

```powershell
Get-FileHash polyrec-vX.Y.Z-windows-x64-setup.exe -Algorithm SHA256
# 出力を SHA256SUMS.txt の該当する行と比べます
```

ビルドの来歴（[GitHub CLI](https://cli.github.com/) が必要です）— ファイルが、このリポジトリのリリースワークフローによって、タグの付いたコミットからビルドされたことを確認します。ファイルを差し替えた人がチェックサムも作り直していれば、バイト列がチェックサムと一致するだけでは見抜けないためです。

```powershell
gh attestation verify polyrec-vX.Y.Z-windows-x64-setup.exe -R yusukensanta/polyrec
```

また、リリースは公開後に変更できません。アセットを後からこっそり差し替えることはできず、変更するにはリリースそのものを削除して作り直す必要があります。

## 動作環境

- Windows 10 2004 以降（ビルド 19041 以降）—「このアプリの音声のみ」で使う Process Loopback Capture API に必要です。
- Direct3D 11 に対応した GPU。

## 機能

- **ウィンドウまたは画面全体のキャプチャ**（Windows.Graphics.Capture）— 表示中の任意のウィンドウか、画面全体を録画するディスプレイを選べます（接続しているモニターはそれぞれ別々に表示されます）。選択したソースのカードにはその画像が表示されるので、録画の前に正しいソースかどうか確認できます。画像は、ソースを選んだときと、PolyRec に戻ってきたときに撮り直されます（最小化中のウィンドウには画像がありません）。録画の解像度は、既定ではソース本来の解像度です。「ディスプレイに合わせる」と「カスタム」は **画質** で選べるオプションです。
- **マルチトラック音声**（**オーディオ**）— システム音声（スピーカー）とマイクを、それぞれ独立したトラックとして録音します。既定ではスピーカーだけが選択されているので、よくある使い方では 1 つのわかりやすいトラックになります。2 つ目のトラックが欲しいときはマイクにチェックを入れてください。チェックした各デバイスには音量スライダー（0〜100%、既定は 100%）があり、録音にだけ効きます。実際に聞こえる音は変わりません。この選択は再起動後も保持されます。
- **このアプリの音声のみ** — デスクトップ全体の音ではなく、選択したアプリのプロセスの音だけを、Windows の Process Loopback Capture API で録音します。
- **アプリごとの音声トラック**（同じく **オーディオ**）— 音を出している実行中のアプリ（Discord、Spotify、ゲームなど）を選んで、それぞれを独立した音声トラックにできます。各トラックに音量スライダーがあります。「このアプリの音声のみ」や映像のキャプチャソースとは独立しているので、録画しているウィンドウでなくても、ここでアプリの音を選べます。同じアプリに属する複数のプロセス（Electron のヘルパープロセスなど）は、重複せず 1 つのトラックにまとめられます。「+ アプリを追加」でアプリ（まだ起動していないものも）を固定すると、そのアプリが記憶され、起動のたびに自動で選択されます。
- **録画枠の切り替え** — 録画中、Windows はキャプチャしているウィンドウやモニターの周りに色付きの枠を描きます。好みに合わせて、メニューバーからオン/オフを切り替えられます。
- **一時停止 / 再開** — 録画を分けずに一時停止と再開ができます。
- **グローバルショートカット** — 録画の開始/停止、一時停止、画面上のオーバーレイの切り替え、ハイライトの保存を、どこからでも実行できます。アプリ内の **ショートカット** で割り当てを変更できます（既定は F9 / F8 / F7 / F10）。ほかのウィンドウにフォーカスがあるときに開始/停止のキーを押すと、リストで選択中のものではなく、*そのウィンドウ* を録画します。ショートカットの操作を知らせる短いメッセージ（オンならオーバーレイも）は、いま使っているモニターに表示されます。ただし、排他的フルスクリーンのゲームの上は例外です。その上にウィンドウを出すとフルスクリーンが解除されてしまうため、ほかのモニターに表示されます（モニターが 1 台だけなら表示されません）。
- **トレイアイコン** — PolyRec は通知領域にアイコンを置きます。クリックするとウィンドウが表示されます。右クリックすると、ウィンドウの表示/非表示、リストで選択中のソースの録画開始（または録画停止）、終了ができます。ウィンドウを隠している間はタスクバーにも表示されませんが、ショートカットは使えます。PolyRec の実行中にもう一度起動すると、実行中の PolyRec が前面に表示されます。ウィンドウを閉じると PolyRec は終了します。メニューバーで **閉じる: トレイへ** にしておくと、代わりにトレイに隠れ、ショートカットは使えるままになります。
- **録画のチェック** — 出力フォルダーの下に、録画先ドライブの空き容量と、現在の画質であとどのくらい録画できるかを表示します（録画前はビットレートから、録画中はファイルの増え方から計算します）。残りが 10 分を切ると琥珀色になり、録画中は一度だけ画面上でお知らせします。また、録画開始から 10 秒たってもマイクからまったく音が入っていない場合も、画面上でお知らせします。たいていはマイクがミュートになっています。
- **録画中のドット** — 録画中は、PolyRec のトレイアイコンとタスクバーのボタンに赤いドット（一時停止中は琥珀色）が付きます。ゲームが画面を占めていても、録画中だとわかります。タスクバーのドットは、**設定 → 個人用設定 → タスク バー → タスク バーの動作 → タスク バー アプリにバッジを表示する** がオンのときだけ表示されます。Windows 11 では、新しいトレイアイコンが **^** の中にしまわれます。PolyRec のアイコンを常に表示するには、同じページの **その他のシステム トレイ アイコン** でオンにしてください。
- **ハイライト** — 任意で有効にできる、直近を保持し続けるバックグラウンドのバッファ（30〜300 秒、設定可能）です。録画していないときも記録を続けます。ハイライト保存のショートカットを押すと、手動で録画を始めていなくても、直前 N 秒を書き出せます。
- **画質設定**（**画質**）— FPS（30・60・120・144・240。ディスプレイのリフレッシュレートが設定より低い場合は、ディスプレイが出せる最も高い標準のフレームレートで録画します。たとえば 165 Hz のモニターなら 144 です。どのファイルも一定のフレームレートで記録されます）、コーデック（H265。HEVC エンコーダーのない環境では自動で H264 に切り替わります。H264 を直接選ぶこともできます）、解像度モード、ビットレート（解像度×fps から自動計算、または Mbps を手動で指定）、エンコーダーモード（既定は GPU のハードウェアエンコーダー。GPU の負荷を減らしたいときはソフトウェア）を設定できます。ハードウェアエンコーダーでは、試験的な **フレームをGPU上で処理** にチェックを入れると、各フレームをシステムメモリにコピーせずにエンコーダーへ渡すので、録画中の PolyRec の CPU 使用率がおよそ 4 分の 3 減ります。録画の映像がおかしいと感じたら、オフにしてください。エンコーダーが対応していない環境では、自動で通常の動作に戻ります。
- **エクスポート** — 録画から必要な音声トラックだけを残したファイルを作ります。再エンコードはしません。
- **アップデートの確認** — 起動時に、今のバージョンを GitHub の最新リリースと比べ、アプリ内での自動アップデートを提案します。インストールされるのは、リリース鍵で署名されたものだけです。
- **English / 日本語** — UI の表示言語を切り替えられます。選択は設定に保存されます。
- **キーボード** — Tab で PolyRec のコントロール間を移動し、Space か Enter でフォーカスのあるものを押し、Esc でポップアップを閉じます。キーボードで移動し始めると、Windows 標準のアプリと同じように、フォーカスの位置を示す枠が表示されます。クリックすると枠は消えます。
- **テーマ** — PolyRec は Windows のライト/ダークモード（**設定 → 個人用設定 → 色**）に合わせて、独自のインディゴ系の配色で表示されます。選択中のものと押せるものはインディゴ、録画は赤です。ハイコントラストテーマでは Windows 自身の配色に切り替わります。**アニメーション効果** をオフにしている場合（**設定 → アクセシビリティ → 視覚効果**）、PolyRec の中では何もアニメーションしません。録画オーバーレイはゲームの上に表示されるため、どのテーマでも暗い配色のままです。
- **文字サイズ** — PolyRec の文字は、Windows 標準のアプリと同じように **設定 → アクセシビリティ → テキストのサイズ** に従い、設定を変えるとすぐに反映されます。ウィンドウも、前回閉じたときのサイズ（と最大化の状態）で開きます。

## 使い方

1. 左のリストからキャプチャソースを選びます。
2. **オーディオ** で、録音する音声トラック（スピーカー / マイク / 実行中のアプリ）を選びます。選択したアプリの音だけにしたい場合は、**このアプリの音声のみ** にチェックを入れます。
3. 既定から変えたいものがあれば、**画質** や **ショートカット** で調整します。
4. **録画**（または開始/停止のショートカット）で録画を始めます。一時停止のショートカットで一時停止/再開し、もう一度開始/停止のショートカットを押すと停止します。
5. 停止すると、エクスポートで最終的なファイルに残す音声トラックを選べます。

録画は `<出力フォルダー>/polyrec/<アプリ名>_<終了時刻>.mp4` に保存されます。出力フォルダーの既定はビデオフォルダーで、アプリから変更できます。

## PolyRec が勝手に終了した場合

PolyRec の実行中にグラフィックドライバーが更新またはリセットされた場合（Windows Update はグラフィックドライバーを自動でインストールします。GPU をクラッシュさせたゲームはドライバーをリセットします）や、PolyRec で予期しないエラーが起きた場合、PolyRec はいったん終了し、自動で再起動します。ゲームの邪魔をしないよう、最小化された状態で起動します。録画中だった場合は、先に録画を停止して保存します。再起動した PolyRec は、何が起きたかをウィンドウの上部に表示します。再起動から 1 分以内にもう一度終了しなければならなかった場合は、何度も繰り返さないよう、終了したままになります。

何が起きたかは、`%APPDATA%\PolyRec` にある設定ファイルの隣の `crash.log` に、PolyRec の実行中の動作は同じ場所の `polyrec.log` に書き込まれます。問題を報告するときは、両方を添付してください。ログには録画したアプリやファイルの名前が含まれます（ウィンドウのタイトルは記録されず、自分のフォルダー内のパスはユーザー名ではなく `%USERPROFILE%` と表示されます）。添付する前に目を通してください。
